# 一起打螺丝 🔩

打工人专属 · 拧紧每一天。一款自嘲向的流水线"打螺丝"休闲小游戏。

**在线试玩：** https://mayingming555-lang.github.io/yiqi-daluosi/

## 玩法
- 上班先打卡，8 点后算迟到。
- 按住螺丝开拧，圆环走到绿区松手 = 拧到位；拧过头会滑丝扣钱，零件溜走算漏拧。
- 十字 / 一字 / 六角三种批头；手机上力度圈会浮在手指上方。
- 老板巡视画饼，摸鱼被抓扣钱；可摸鱼或喝奶茶回血。
- 日结工资条 + 每 5 天月结；可保存工资条、生成打工战报分享。
- 普工一路升到老板；线长起可买期权，偶尔上市敲钟。
- 成就系统；排行榜含月薪、今日合格件数、最长连击。

传送带每天提速约 5%，封顶 2.5 倍。单文件 HTML5。纯属虚构，如有雷同，那你也在打螺丝。
