# 一起打螺丝 🔩

打工人专属 · 拧紧每一天。一款自嘲向的流水线"打螺丝"休闲小游戏。

**在线试玩：** https://mayingming555-lang.github.io/yiqi-daluosi/

## 玩法
- 上班先打卡，8 点后算迟到。
- 按住螺丝开拧，圆环走到绿区松手 = 拧到位；拧过头会滑丝扣钱，零件溜走算漏拧。
- 十字 / 一字 / 六角三种批头，要换对才拧得动。
- 老板会来巡视画饼，摸鱼被抓扣钱；精力低了可以摸鱼或喝奶茶。
- 每天发日结工资条，每 5 天发一次月底工资，可保存成图片分享。
- 从普工一路升到老板……然后你会发现老板也在打螺丝。

单文件 HTML5，无外部依赖，手机电脑都能玩。纯属虚构，如有雷同，那你也在打螺丝。
